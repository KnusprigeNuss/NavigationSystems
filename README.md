# NavigationSystems

## Version
- **Programming Language**: Python 3.12
  - **Additional Packages**: pandas, folium

## Runtime
- **Per Task**: ~15 seconds per task

## Execution
Enter the Number of the task:
1. **Task 2.1 with time as a cost-function**
2. **Task 2.1 with distance as a cost-function**
3. **Task 2.2 with pedestrian mode (no car ways)**
    - Prioritize flags: 4, 5, 6, 7
4. **Task 2.2 with car mode**
    - Prioritize highway class numbers: 11, 12, 15, 16, 21, 22
    - Prioritize flags: 1, 3, 5, 7

`Task2-1.html/Task2-2.html`: Results of the algorithm.

After executing a task, the routes are displayed in the `map.html` file.
